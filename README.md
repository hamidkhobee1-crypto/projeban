# پروژه‌بان — v2.23.0

اپلیکیشن **تک‌فایلی کاملاً آفلاین** برای بایگانی، جمع‌بندی و پیگیری پروژه‌ها (فارسی RTL، تقویم جلالی، پومودورو، کانبان، گانت/CPM، تایم‌باکسینگ).

## اجرا (سه راه)
1. **آنلاین با GitHub Pages:** اگر این مخزن Pages دارد — `https://<user>.github.io/<repo>/` را باز کنید.
2. **محلی:** فایل `index.html` را دانلود و در کروم/ادج/فایرفاکس باز کنید — همین!
3. **نصب به‌صورت اپ:** از داخل برنامه (تنظیمات ← ابزارها) بستهٔ نصب را بگیرید و اجرا کنید.

## تازه‌های ۲٫۲۳٫۰ — بستهٔ ارتقای رقبا (بررسی ۱۰ رقیب)
1. **روز من (My Day)** — ستارهٔ ☀ هر پیگیری آن را برای امروز برجسته می‌کند؛ کارت «روز من» بالای تب پیگیری‌ها (الگوی Any.do / Microsoft To Do).
2. **ماتریس آیزنهاور** — نمای سوم پیگیری‌ها؛ چهار خانهٔ فوری×مهم با راهنمای تصمیم (الگوی TickTick).
3. **برچسب‌های رنگی کارها** — انتخابگر در مودال + چیپ روی ردیف/کارت/ماتریس + فیلتر برچسب (الگوی Trello).
4. **افزودن سریع هوشمند** — «@برچسب #پروژه !بالا فردا …» خودکار پارس می‌شود (الگوی Todoist).
5. **باغ تمرکز + امتیاز/سطح/زنجیره** — هر نشست پومودورو یک درخت 🌳 (الگوی Forest + Habitica/Karma).
6. **حالت تمرکز تمام‌صفحه** — تایمر بزرگ و درخت رشدکننده در پنل پومودورو (Esc = خروج).

## انتشار نسخه روی همین مخزن
از داخل اپ: تنظیمات ← گروه «داده‌ها و پشتیبان‌گیری» ← کارت گیت‌هاب ← «انتشار نسخه» — فایل index.html همین مخزن به‌روز می‌شود و Pages تازه می‌ماند. (نیازمند اتصال یک‌باره با Fine-grained PAT — فقط همین بخش اینترنت مصرف می‌کند.)

## حریم خصوصی
همهٔ داده‌ها فقط در مرورگر خودتان (IndexedDB)؛ هیچ سروری، هیچ آنالیتیکسی. گیت‌هاب فقط اگر خودتان فعالش کنید.
